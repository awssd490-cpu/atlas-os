# Atlas v0.7.5-alpha — Hybrid Retrieval

Release Date: July 2026

---

## Overview

This release completes Atlas's Retrieval-Augmented Generation (RAG) retrieval stack.

The framework now supports:

- Document ingestion
- Multi-strategy chunking
- Embedding providers
- In-memory vector storage
- Hybrid keyword + semantic retrieval
- Automatic context construction

Hybrid retrieval is automatically enabled whenever an embedding provider and vector store are configured, while remaining fully backward compatible with existing keyword-only workflows.

---

## Highlights

### Hybrid Retrieval

Added a new hybrid retrieval subsystem capable of combining:

- Keyword retrieval
- Semantic vector retrieval

using configurable fusion algorithms.

Supported fusion strategies:

- Weighted Sum
- Reciprocal Rank Fusion (RRF)

---

## Automatic Retrieval Selection

KnowledgeContextBuilder now automatically chooses the optimal retrieval strategy.

Without embeddings:

KnowledgeBase
→ Keyword Retrieval

With embeddings + vector store:

KnowledgeBase
→ Hybrid Retrieval

No application code changes are required.

---

## Embedding Subsystem

Added a complete embedding abstraction including:

- EmbeddingProvider interface
- DeterministicEmbeddingProvider
- MockEmbeddingProvider
- Registry
- Config models
- Batch embedding support

---

## Vector Store

Implemented a memory vector store featuring:

- Vector CRUD
- Similarity search
- Cosine similarity
- Dot product
- Euclidean distance
- Dimension validation
- Capacity limits
- Deterministic ordering

## Performance

Current complexity:

Keyword Retrieval

O(k × t)

Semantic Retrieval

O(n × d)

Fusion

O(m log m)

where:

k = keyword candidates

n = vector count

d = embedding dimensions

m = fused candidates
